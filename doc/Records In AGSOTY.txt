

swimming records in AGSOTY

Jan 19, 2026: Chris wrote me asking the following:

	It is possible that some records could be broken more than once and I know I need 
	to make sure I approve these in order. So say Joe breaks a record at our SCY champs 
	and then Steve breaks that record at Nationals, they both get AGSOTY points for that, 
	right? What if Joe breaks his own record again (instead of Steve)?

My reply on the same day:

	OK, I have an answer to your questions.
	First of all, I found an old document written when our new records system was being designed. 
	Here is an excerpt with some clarification surrounded by “[ ]”’s:
	
	1.              Age Group Standings [AGSOTY] will assign Pac records points based on transactions 
	in this repository [the new database and tools we’re designing].  This will allow us to reward 
	multiple individuals who better a given record during a season.  (And, we can keep from awarding 
	multiple points if one individually lowers a record more than once in a season.)
	
	Notice that the above implies that if Sally breaks the same record multiple times in a 
	season she gets points for all records BUT WE CAN KEEP THAT FROM HAPPENING IF WE WANT. 
	The term “multiple individuals” is unclear but could mean that if Sally and Jane both 
	break the same record in the same season then both get points.
	
	My reading of the code agrees with the above AND DOES NOT PREVENT SOMEONE FROM GETTING 
	MULTIPLE POINTS FOR BREAKING THE SAME RECORD MULTIPLE TIMES IN THE SAME SEASON. In your 
	example below, both Joe and Steve get AGSOTY points. And Joe gets points for every time 
	he breaks the same record in the same season.

So it seems that the intention of the "old document" referenced above is:
	1. if two people break the standing record for the same event in the same season then
		both get points. So, using Chris' example, both Joe and Steve get points.
		Currently it appears that the code for PMS records does this.
	2 if the same person breaks the standing record for the same event in the same season
		then that person only gets points for one of the records. Currently it appears 
		that the code for PMS records DOES NOT DO THIS. (It gives that person points for
		each time they broke the record.)

Furthermore, the code handling USMS records does not handle #1 correctly. It only gives the
current record holder points if the current record holder broke the record during the season
being processed. I think it
handles #2 correctly, but only accidentally.
